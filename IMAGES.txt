HOW TO SWAP AN IMAGE
1. Make your new image the same shape (brick phone photos are 3:4 portrait; screens are wide).
2. Name it EXACTLY like the old one and replace the file inside the images folder.
3. On GitHub: open the images folder, Add file > Upload files, drop the new one in, and commit.
